HDMI Switch + Klipsch Control Console

Hardware Controller v2.2 · 3-input HDMI switch · Klipsch R-15PM wired NEC · Dell browser test tool

This file runs directly on the Dell after flashing ShopShell Hardware Controller v2.2. Commands are sent by browser POST forms to the ESP32; returned JSON is displayed below. Because the page is local and the ESP32 is another origin, it cannot automatically interpret the response or know whether the HDMI switch or speakers physically responded. Record Pass/Fail after observing each action.

3-input HDMI switch

ESP32 open-drain button emulation

Each command emulates one 160 ms press on the switch's passive wired remote. Observe the ViewSonic and source LEDs after every click.

Direct source selection

Manual cycle

Cold-boot target: firmware waits 3 seconds, selects Dell/Input 1, then reasserts Dell once 2.5 seconds later. After a station cold boot, the switch should always settle on ShopShell.

Installed wiring

GPIO27 → remote pin 1 → Input 1 / Dell
GPIO32 → remote pin 3 → Input 2 / PS4
GPIO33 → remote pin 2 → Input 3 / Apple TV
GPIO21 → remote pin 4 → Cycle
remote pin 5/common → ESP32 GND

All four signal GPIOs are open-drain: HIGH = released/high-Z, LOW = pressed. The HDMI switch supplies its own ~3.27 V pull-ups.

General RS-232 bridge retained

GPIO16 RX / GPIO17 TX, 38,400 8N1, raw TCP port 2323. AP5-specific automatic commands are removed; the bridge remains available for future hardware.

Port 2323 (general RS-232 bridge)

ViewSonic + appliance orchestration

TCP 5000 · CEC-enabled display

The ESP32 now coordinates the IFP6570 over native ViewSonic LAN control. Boot audio is fail-safe: the panel must acknowledge upstream mute before the controller will drive the Klipsch to maximum gain.

Display control

System behaviors

Automatic boot: Dell/Input 1 is selected locally, then after Wi-Fi the controller mutes the ViewSonic, sends 70 Klipsch Volume Up presses, selects Optical, waits for the NEC queue to settle, and unmutes the ViewSonic. If mute cannot be established, the gain ramp is skipped.
Shutdown test: /system/shutdown puts the ViewSonic into standby. With CEC enabled, the display may also send a power-off instruction to the active CEC source.

Klipsch R-15PM

GPIO25 → 2N2222 → wired IR DATA

Logical NEC address 0x02; 38 kHz carrier disabled. The wired Power, Volume Up, and Optical functions were previously tested on your speakers.

Volume caution: Your desired amplifier startup setting is maximum. Keep the upstream audio source muted/very low when testing volume increases and especially any batch ramp.

Power and mute

Amplifier volume

A single firmware request accepts at most 10 presses. Allow ~2–3 seconds between ten-step batches to prevent queue saturation.

Source selection

Subwoofer level

Playback and indicator

LED indicator tests may be invisible if the original front IR/LED PCB remains disconnected. Play/Pause and Previous depend on selected playback source. Next Track has no confirmed code and is not exposed as a fixed command.

Full-gain commissioning test

Optional, manual-only. Send up to 100 Volume Up presses as paced batches of 10, ~3 seconds apart. This is for evaluating startup behavior; it is not automatically run when opening the page.

Idle

Stopping cancels future requests but cannot revoke commands already queued on the ESP32. The page cannot automatically detect amplifier volume or the live queue.

Manual NEC experiment

Test an undocumented 8-bit logical command on NEC address 0x02 through the existing guarded firmware route.

Firmware validates manual codes and limits them to 1–3 presses and 0–2 repeat frames. Unknown codes may change unexpected settings; test with audio muted and note the results.
